# FAQ

## 如何快速开始一个根据头型推荐发型的应用？

下面是一份可以直接落地的路线图，涵盖数据、模型、产品到测试的关键节点：

- **明确输入与输出**：
  - 输入：用户上传的正脸或半侧脸照片（提醒用户提供充足光线、露出额头）。
  - 输出：3~5 个匹配度高的发型方案（含示意图、理由、维护成本）。
- **头型/脸型识别**：
  - 首选可用现成的开源人脸分析模型（如 MediaPipe Face Mesh）提取 468 关键点，计算脸型特征（长宽比、下颌曲率、额头宽度等）。
  - 如果要区分更多细分脸型，可在公开人脸数据集上做小样本微调，增加“椭圆/菱形/心形/圆形/长形”等标签分类头。
- **发型特征库**：
  - 收集经过授权的发型照片，记录脸型适配标签、额头遮挡程度、刘海/分发/卷度/长度等元数据。
  - 使用 CLIP 一类的多模态模型为发型图片生成向量嵌入，便于后续相似度召回。
- **匹配与推荐算法**：
  - 第一阶段基于脸型类别做过滤，排除明显不适配的发型。
  - 第二阶段用向量检索（Faiss/Milvus/PGVector）在嵌入库里做相似度召回，可额外加规则（如“圆脸避免过短刘海”）。
  - 第三阶段用 rerank 模型或简单打分函数综合脸型匹配度、发型特征权重、用户偏好（如长度、染色）给出最终 Top-N。
- **端到端产品流程**：
  1. 前端：上传图片 + 选项（性别、长度、是否可染）。
  2. 后端：图片压缩与安全检测 → 关键点/脸型识别 → 向量检索与规则过滤 → 生成推荐列表。
  3. 结果呈现：展示发型示意图、适配理由（突出脸型几何、额头遮挡、视觉拉长/收窄效果），可附带维护难度与日常打理建议。
- **质量与验证**：
  - 建立小型标注集（用户图片 + 专业发型师标注的可行/不可行发型），用准确率/命中率评估。
  - A/B 测试：比较“纯规则” vs “规则+向量检索”方案的点击率和保存率。
  - 用户反馈闭环：收集“喜欢/不喜欢”信号，定期增量训练或更新权重。
- **体验与合规注意事项**：
  - 隐私：上传即处理、默认不存原图；必要时做脱敏和加密存储，提供删除入口。
  - 体验：提示用户拍摄条件，检测模糊/遮挡时给出重拍建议；提供“风格偏好”快速选项避免结果同质化。
  - 模型可解释性：在推荐理由中引用具体几何特征（如“下颌较窄，选择层次感短发提升横向体积”）。
- **扩展方向**：
  - 支持虚拟试戴：使用 3DMM 或人脸驱动的生成模型将发型贴合到用户照片。
  - 多模态交互：允许用户上传参考明星/角色造型，直接做“以图搜图”匹配。
  - 美发门店/电商联动：将推荐结果绑定附近门店的可执行方案或商品链接。
